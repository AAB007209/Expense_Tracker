## Expense Tracker - [Live Demo](https://expense-tracker-bice-kappa-14.vercel.app/)
Expense Tracker is a web application designed to help users monitor their personal finances by tracking income and expenses.

### Features
- Income and Expense Tracking: Add and manage your income and expenses to maintain an up-to-date financial overview.
- Real-Time Balance Calculation: View your current balance, along with total income and expenses, updated in real-time.
- User-Friendly Interface: Navigate through a clean and intuitive interface for seamless expense management.

### Usage
- Add a Transaction: Click on "Add" to input a new income or expense.
- Enter Details: Specify the transaction name and amount.
- Save Transaction: Click "OK" to add the transaction to your history.
- View Balance: Monitor your updated balance, income, and expenses on the main dashboard.
